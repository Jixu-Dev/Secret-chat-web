## 🔐 Overview

**Secret Chat** is a real-time, privacy-first chat application powered by **Firebase**. Built with a modern stack of **Vite + Tailwind CSS v4**, it provides instant messaging with a sleek, dark-mode interface designed for secure and private conversations.

---

## ✨ Features

- 💬 **Real-Time Messaging** — Instant message delivery via Firebase Realtime Database / Firestore
- 🔥 **Firebase Integration** — Authentication, database, and hosting
- 🌙 **Dark Mode Interface** — Premium dark aesthetic built with Tailwind v4
- ⚡ **Blazing Fast** — Vite 8 build system with instant HMR
- 📱 **Responsive Design** — Seamless experience across all devices
- 🛡️ **Privacy-First** — Designed with user privacy as a priority

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Jixu-Dev/Secret-chat-web.git
cd Secret-chat-web

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

> **Note:** You'll need to set up a Firebase project and add your config to use authentication and database features.
